# Mandala Maker

Emoji kaleidoscopes, spun to order. A single-file web app — no build step, no dependencies.

## Live

https://aditiohri.github.io/emoji-mandala-creator/

Open it on your phone and use "Add to Home Screen" — it installs as a standalone app.

## Files

- `index.html` — the whole app
- `manifest.webmanifest`, `icon*.{svg,png}` — home-screen install metadata
